# 低 token 检索与商业章纲评分

仅在素材检索、素材支撑的方案生成或章纲商业性审核时读取本文件。

## 一、先形成最小状态包与情绪任务单

优先读取当前卷相关段落、前一章、最近3—5章摘要、项目中的活跃伏笔/承诺/情绪债账本、相关人物条目和当前规则条目。整理成不超过600字的状态包：当前阶段任务、前章问题、主角目标与缺口、在场人物及知情边界、待兑现伏笔、活跃读者期待、近期机制与钩子、本章禁区。

摘要能确认时不读整章；只有动作细节、空间位置或原句承接无法确认时才打开正文。没有状态账本时，不假装不存在旧伏笔；用人物名、承诺物、冲突对象和目标词定位相关旧摘要。

检索前输出一张简短“情绪任务单”：

| 字段 | 要求 |
| --- | --- |
| 主情绪 | 本章最希望读者产生的一种情绪 |
| 辅情绪 | 最多两种，用于丰富而非抢主线 |
| 情绪对象 | 读者为什么替谁期待、担心、愤怒或高兴 |
| 当前蓄压 | 已有哪些铺垫；没有铺垫则不能假装强兑现 |
| 兑现级别 | 继续蓄压、阶段小兑现、本章强兑现或兑现后余震 |
| 可见证据 | 对手反应、旁观者认知、关系动作、公开结果、代价回响等 |
| 章末余味 | 兑现后希望读者带走的新期待 |

用户已经明确情绪时直接使用。上下文指向单一答案时，说明判断后继续。若不同情绪会实质改变检索结果，且项目规则允许，则先问一个简短问题确认；不能提问时按最推荐方向继续，并清楚标注假设。

## 二、两阶段检索

### 第一阶段：紧凑召回

把状态包与情绪任务单转换为：`query`（主情绪＋蓄压/兑现方式＋可见证据＋事件功能，共2—4组）、`modules`（优先模块）、`exclude`（阶段禁用词）和 `limit`（默认12，简单任务8）。不要只搜场景名或敌人名。

~~~powershell
python "素材库/tools/material_library.py" search `
  --library "素材库" `
  --query "紧张 智斗爽 团队认可 公开反超" `
  --modules "战斗,人物关系,钩子" `
  --exclude "越阶突破,高层关注,永久能力" `
  --limit 12
~~~

不要把完整总索引或标签索引读入上下文。脚本输出只用于召回，不等于最终采用。

### 第二阶段：全文复核

按以下优先级筛到2—4张原卡：

`当前因果 > 目标情绪匹配 > 活跃期待与铺垫 > 人物与信息边界 > 阶段任务 > 前提满足度 > 近期冷却 > 原创改造空间 > 来源成熟度`

逐张核对使用前提和风险。需要完整连续结构时，才读取对应 `book_structure_summary.md` 或 `intra_book_clusters.md`；仍不足再读拆解章节。默认不读源文。

## 三、组合和回执

单章优先使用：`1个主机制 + 0—1个辅助机制 + 1个钩子机制`。

主机制负责本章情绪曲线，辅助机制只能加强人物关系、资源代价或信息差，不能抢走主情绪。钩子负责兑现后的新期待，不得用突发危机掩盖本章尚未兑现的核心承诺。

输出必须给出简短调用回执：

| 项目 | 内容 |
| --- | --- |
| 实际读取 | 2—4张原卡ID与路径 |
| 情绪任务 | 主情绪、当前蓄压、兑现级别与可见证据 |
| 采用组合 | 主机制、辅助机制、钩子 |
| 弃用候选 | 至少说明最相近候选为何不合适 |
| 原创映射 | 重设的触发、人物、资源、场景、兑现或后果 |
| 情绪落地 | 铺垫如何转成读者可见的兑现与余震 |
| 冷却结论 | 与最近章节是否重复 |

回执与正式章纲分离；不得让正文创作反复读取审计元数据。

## 四、番茄商业章纲评分

评分用于暴露缺口，不能替代事实一致性。任何硬约束冲突直接 `FAIL`。

| 维度 | 分值 | 判定重点 |
| --- | ---: | --- |
| 承接与现在发生的理由 | 12 | 是否由前章、活跃期待和阶段目标自然触发 |
| 目标情绪匹配 | 15 | 方案是否真的服务用户指定的主情绪 |
| 蓄压与情绪曲线 | 10 | 期待、加压、转机、兑现是否有递进 |
| 可见兑现证据 | 15 | 是否有反应、认知变化、关系动作、公开结果或代价回响 |
| 主角目标与主动选择 | 12 | 主角是否行动、承担代价并改变结果 |
| 冲突清晰与升级 | 10 | 阻力是否具体且至少升级一次 |
| 状态变化与收益 | 8 | 实力、资源、关系、信息、名次、地图或风险是否变化 |
| 小闭环 | 6 | 本章承诺是否至少部分落地，而非全部延期 |
| 章末追读问题 | 6 | 是否产生明确的新目标、收益、危机或认知缺口 |
| 新鲜度与冷却 | 6 | 是否改变近期重复的冲突、解法、围观或钩子形式 |

推荐门槛：80分。70—79分允许作为待优化候选；低于70分应重新检索或重组。没有明确主情绪，或“可见兑现证据”低于8分的方案，即使总分达到80也不能直接推荐。准备章可以选择“继续蓄压”，但必须明确将哪项期待推向什么兑现窗口。

## 五、三个方案的差异要求

A稳妥、B变化、C新鲜三个方向，至少在主情绪、主角目标、核心冲突、主机制、兑现方式、章末钩子六项中改变两项。若用户已经锁定主情绪，则三案保持主情绪一致，但必须改变蓄压方式、兑现证据或余震中的至少一项。只换敌人名字、场景皮肤或技能表现不算不同方案。

主动推荐时说明因果顺畅度、节奏位置、近期重复风险、后续推进价值和评分短板。评分最高不必然最推荐；违反人物逻辑或需要重大未冻结设定的方案不得推荐。
