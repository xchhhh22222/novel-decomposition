# 世界观机制聚类与 QA 规则

本文件只规定 `novel-worldbuilding-miner` 的派生分析、聚类和质量审核方法。正式字段以同目录 `schema.md` 为准；本文件不得新增未写入 schema 的正式字段，也不得把审核判断写回原始书籍事实。

## 一、审核层级

按以下顺序审核：

1. 输入与证据范围是否冻结且可追溯；
2. 单书是否提取出可观察的世界机制，而不是名词清单；
3. 因果链是否成立，缺口是否被诚实标为 `partial`、`UNKNOWN` 或 `gap`；
4. 所有单书 QA 完成后，再进行跨书 nearest-neighbor 与 clustering；
5. 最后审核 handoff 是否保留候选边界、证据、未知项和不确定性。

任何层级失败都不得靠后续聚类或更强的措辞覆盖。世界观记录默认是候选分析，不得直接变成正式素材卡、世界观定稿或本书事实。

## 二、单书 QA

### 2.1 输入、范围与证据

- 检查目标书、章节范围、来源路径和提取版本是否与冻结任务一致。
- `per_book` 的每个机制必须能沿 `evidence_refs` 回到原文或已确认拆书成果；不能只写“原文体现”“前期设定”等不可定位描述。
- 同一书中近义、同义或上下位混写的规则要去重并标注合并依据；不能把“能源不足”“资源稀缺”“供给受限”无证据地拆成三个机制。
- 书内互相冲突的规则不得强行选定一个版本。应保留冲突证据，降级为 `UNKNOWN` 或 `HOLD`，并说明冲突位置与需要核验的前提。
- 禁止把金手指输入/处理/输出、修炼境界与突破循环、人物功能、主线冲突或开篇流程写成世界观结论；必要时只作为相邻专项待核验线索。
- 情绪信息只能作为 `emotion_overlay` 的引用或 QA 辅助，不得复制章节情绪 schema，也不得用情绪判断替代世界规则证据。

### 2.2 名词清单与有效机制区分

仅出现以下名词，不足以构成世界观机制：武大、军方、秘境、异族、禁区、财团、遗迹、城池、职业、等级或地图名称。

只有当原文能证明该对象如何改变至少一个可观察结果时，才可进入有效候选，例如：

- 改变资源取得、分配、价格、资格或风险；
- 改变制度约束、组织权力、身份门槛或行动许可；
- 改变冲突生成、重复任务、地图进入条件或信息流动；
- 改变人物选择、读者可见的代价或后续剧情入口。

若只有名词而没有规则作用，标为弱证据或 `gap`，不得升为高置信世界机制。

### 2.3 因果链有效性

使用下列主链检查，但不要求每条记录都填满所有节点：

`规则 → 稀缺 → 利益/制度 → 冲突 → 剧情入口 → 读者情绪`

逐链检查：

1. **规则**：说明世界中什么能做、不能做、必须付出什么，或什么稳定地决定结果。
2. **稀缺**：说明被限制、争夺、垄断或高风险获取的资源、资格、位置、时间、信息或安全空间。
3. **利益/制度**：说明谁因此获利、受限、分配、监管、垄断或承担责任。机构存在不等于机构已影响剧情。
4. **冲突**：说明规则和稀缺如何生成可重复的对抗、谈判、竞赛、封锁、违规或代价。稀缺存在也不自动等于利益冲突。
5. **剧情入口**：说明机制如何让人物必须行动，或如何打开任务、地图、身份、资源、信息差和后续事件。只发生一次的偶然事件不能自动视为持续机制。
6. **读者情绪**：只记录原文可观察的情绪效果或与情绪专项的引用关系，不凭常识替作品补写情绪。

最低有效候选为：`规则 + 至少一个可观察后果`。后果可以落在稀缺、制度、冲突、剧情入口或情绪中的任一项；缺少后果时应降级为 `partial`、`UNKNOWN` 或 `gap`。

QA 必须区分：

- **作者/叙事声称的规则**：角色、旁白或设定文本宣称如此；
- **被剧情验证的规则**：至少有行动、限制、代价、结果或他人反应展示其确实运作。

没有验证证据时，不得把声称写成已证实的硬规则，也不得用常识填补因果缺口。

### 2.4 世界机制专项有效性

- 地图扩张必须说明新增或改变了什么规则、资源、制度、威胁或信息边界；只换地点名称不算规模升级。
- 威胁生成器必须解释威胁如何反复产生、升级或迁移；单次灾难、单个敌人或一次偶发事件不能自动充当持续世界机制。
- 信息控制必须说明谁知道、谁不知道、信息如何被隐藏/验证/传播，以及信息差如何进入人物选择或冲突。
- 组织、机构和制度必须至少有一项可观察的行动后果；“有军方”“有学院”本身不构成制度机制。
- 资源稀缺必须有获取、分配、封锁、替代或代价证据；“资源珍贵”本身不足以推出利益结构。

## 三、世界观节奏与疲劳 QA

以下是审核判断，不新增正式 schema 字段。可在 `qa` 的说明、风险或建议中记录证据与结论：

- 是否出现第一次世界展示、第一次规则验证、第一次尺度升级；
- 是否连续解释规则却没有行动、限制、代价或结果验证；
- 是否连续堆叠设定，迟迟没有剧情入口；
- 新地图是否只改变地名、风景或名词，而没有机制变化；
- 是否重复使用同类机构、资源或威胁，却没有改变其运作方式、利益关系或风险；
- 解释密度是否让人物选择、冲突推进和情绪兑现停滞。

识别到疲劳时，优先提出“用行动验证既有规则”“让新制度产生选择代价”“让地图改变资源/信息/威胁结构”等可执行建议，不得为了消除疲劳强行新增世界硬规则。

## 四、跨书 nearest-neighbor QA

只有所有目标书完成单书 QA，且输入范围、证据可追溯性和关键未知项已经处理后，才能进行跨书比较。

nearest-neighbor 必须比较机制结构，而不是表面词：

- 规则如何造成稀缺；
- 稀缺如何进入利益、制度或组织分配；
- 冲突是否可重复生成，以及重复生成的条件；
- 机制如何打开剧情入口；
- 信息控制和地图扩张如何改变行动边界；
- 机制实际承担了什么读者情绪功能。

每个邻近关系必须同时写出：

1. 相似点：至少落在一个可验证的因果环节或链路组合；
2. 关键差异：指出规则、资源、制度、冲突、入口或信息边界的不同；
3. 证据：分别回指参与比较的书籍记录与 `evidence_refs`；
4. 未知项：说明哪些相似/差异仍是假设，不能被当作已确认结论。

仅凭“都有秘境”“都有学院”“都有异族”等共现词，不得建立邻近关系。

## 五、跨书 clustering QA

聚类单位是可复用的因果链或机制组合，不是世界名词、题材标签或地点名称。聚类前应确认：

- 每本书已经通过单书 QA，或明确标记其 QA 缺陷；
- 聚类中的共同机制在各书中都有最低证据；
- 组内相似性来自规则运作方式，而非同词异义；
- 组外差异不会被一句宽泛标签抹平；
- 每个簇都有代表性证据、边界、反例或未决项。

允许使用：

- `unclustered`：存在机制记录，但不足以与其他书形成可靠共同因果结构；
- `insufficient_evidence`：表面相似已出现，但证据不足以确认同类机制；
- `HOLD`：存在冲突或高影响未知项，暂缓归簇。

不允许为满足数量、完整度或覆盖率而强行聚类。QA 失败的书不得支撑 `HIGH` 置信聚类；如果仍保留在比较中，必须降低置信度并列出缺口。

## 六、回收与交接检查

### 6.1 `qa`

`qa` 至少应能回答：

- 哪些单书机制有充分证据；
- 哪些规则只是声称，哪些已经被剧情验证；
- 哪些因果链节点缺失；
- 哪些名词被误当成机制；
- 哪些重复、冲突、跨书比较或节奏疲劳需要处理；
- 是否存在影响 handoff 的 `UNKNOWN`、`gap` 或 `HOLD`。

### 6.2 `handoff`

交接时只传递候选机制、证据、差异、未知项、待核验问题和适用边界。不得把聚类名直接当正式卡名，不得写入本书永久能力、重要势力、世界硬规则或不可逆事件结果。

### 6.3 完成判定

世界观专项只有在以下条件同时满足时才可标记完成：

- 五类输出均有记录或明确的空结果说明；
- 单书与跨书 QA 均已执行；
- 关键证据可回溯；
- `partial`、`UNKNOWN`、`gap`、`HOLD` 没有被伪装成完整结论；
- 没有越界替代金手指、修炼体系、人物、主线、开篇、卷结构或剧情机制专项；
- 没有把候选分析写入正式素材库或本书正式设定。
