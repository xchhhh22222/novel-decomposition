# 创作内核 V1.4

创造层与拆书层严格分工：

```text
拆书层：忠实抽出每本书实际存在的组件
创造层：从多本书选择组件，重新组合成新书候选
```

某一本参考书只有一套或两套体系完全正常。新书需要多体系时，可以跨书选取，但必须重新设计兼容关系，而不是简单拼贴。

## 推荐因果顺序

```text
读者承诺
→ 主角核心欲望与核心矛盾
→ 世界持续制造的问题
→ 势力与资源控制
→ 选择 1～N 套候选修炼体系
→ 重新设计体系关系与境界验证
→ 配置功法、法宝/装备和资源循环
→ 金手指改变效率但不消灭问题
→ 人物关系改变选择
→ 可重复故事循环
→ 阶段升级与疲劳刷新
```

## 组件化组装

创作时可以分别检索世界规则、factions、cultivation system、realm、technique、artifact、resource、system_relation、金手指、人物关系和高潮结构。

允许：

```text
BOOK_A 的资源竞争逻辑
+ BOOK_B 的武道 system 运行结构
+ BOOK_C 的精神 system 运行结构
+ BOOK_D 的成长型 artifact 机制
```

组合后必须成为新的候选世界，不得继续使用来源书的专名、原境界串、原组织组合和连续事件链。

## 多体系组合门

两套以上体系时必须明确：各自解决什么问题、谁能进入、是否兼修、是否争夺同一资源、是否互补/互斥/克制/转化、各自境界如何验证、是否需要跨体系战力映射、主角为什么选择以及组合会制造什么新代价。

没有必要时不要为了“丰富”强塞很多体系。两套能持续制造剧情，优于五套只剩名词。

## 功法、法宝与资源

功法必须明确适配体系、训练方式、核心效果、限制和代价。
法宝/装备必须明确适配体系、激活方式、能源/消耗、效果、限制和成长。
资源必须说明来源、获取权、消耗口与稀缺。

跨来源组合时必须重新设计接口，不能只改名字。

## 世界—势力—修炼—资源闭环

```text
世界规则制造稀缺
→ 势力争夺并控制资源/资格/信息
→ 修炼体系规定成长门槛
→ 功法与法宝改变具体能力
→ 资源进入训练、装备和突破
→ 金手指改变利用效率
→ 成长结果改变身份、关系与势力位置
→ 新位置产生更高层问题
```

## 金手指

金手指仍必须完整定义名称、输入、处理、输出、首次验证、限制、成本、失败、暴露风险、克制和阶段成长。V1.4 还必须说明它具体影响哪个 system / technique / artifact / resource，以及为什么不会无代价消灭中心矛盾。

## 原创映射

每次组合多个来源，至少重设以下四项以上：世界前提、势力利益、system 能量来源、realm 命名与突破、technique 训练与效果、artifact 激活与成本、资源入口、金手指限制、人物关系、验证场、兑现与后果。

多个连续维度高度相似时必须重构，不能靠改名通过。


## V1.2 资源二分

### 普通成长资源

负责日常循环：获取、消耗、兑换、训练、突破、装备供能。可以是晶核、丹药、材料、货币、积分等。

### 战略目标物

负责阶段期待与高潮。它必须让主角有“现在必须拿”的理由，也让竞争者和势力有独立利益。

设计顺序：

`当前致命需求 → 战略目标物能解决什么 → 线索如何出现 → 谁控制/谁也需要 → 进入门槛 → 多方势力入局 → 高潮兑现 → 赢后的代价 → 推出下一阶段`

目标物的名字可以有强记忆点，但名称不能替代功能和冲突。
