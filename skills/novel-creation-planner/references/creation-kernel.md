# 创作内核

先形成可持续故事引擎，再选择单个金手指。推荐因果顺序：

```text
读者承诺
→ 主角核心欲望与核心矛盾
→ 世界持续制造的问题
→ 修炼与资源的成长门槛和验证方式
→ 金手指改变效率但不消灭问题
→ 人物关系改变主角选择
→ 可重复故事循环
→ 阶段升级与疲劳刷新
```

## 金手指

推荐案必须把金手指写成可直接进入开书讨论的 `【候选设定】`，不能停留在类型词。至少回答：

- 正式名称、读者口语简称与命名理由；
- 输入、处理、输出；
- 首次激活场景、主角如何理解、前三章怎样验证；
- 初始功能逐条写明触发条件、作用对象、可观察结果和数值/范围边界；
- 激活条件、限制、成本、失败和暴露风险；
- 世界怎样持续供应输入；
- 修炼体系怎样验证输出；
- 对手怎样克制、误导或利用它；
- 它会制造什么新问题；
- 30、60、120、200、300章分别解锁什么规则、组合或权限，以及为什么不会沦为只涨数值。

金手指不能无代价解决故事的中心矛盾。若能力越强，至少有一种稀缺输入、选择成本、身份风险、时间窗口、关系代价或不可逆构筑限制同步增长。

## 核心人物关系

重要人物都必须具有自己的目标、资源或信息、相容与冲突理由、可改变状态，以及不依赖主角也会采取的行动。

关系网应覆盖若干不同功能：竞争镜像、制度入口、能力互补、情感锚点、秘密边界、价值观对手、长期合作中的利益冲突。不能让所有人只负责认可、打脸、送资源或等待主角拯救。

每个阶段至少发生一种关系状态变化：结盟条件改变、信任增减、利益交换、秘密暴露、责任转移、立场分化、合作升级或阶段退出。

## 世界—修炼—资源闭环

```text
世界制度制造稀缺与竞争
→ 修炼体系规定成长门槛与验证方法
→ 资源系统提供来源、库存、消耗和风险
→ 金手指改变利用方式但不取消稀缺
→ 成长结果改变身份、关系和主线位置
→ 新位置产生更高层问题
```

资源至少记录来源、获取权、库存、消耗口、损耗、可见价值、争夺、通胀控制与阶段替代。身份、权限、知识和关系资源不能自动当成战力提升。

推荐案必须显式命名并定义：

- 时代与灾变/变革起点、当下社会矛盾、普通人的生活接口；
- 主要地理层级、城市/学校/组织/前线如何连接；
- 至少3个会主动行动的核心机构及其利益冲突；
- 修炼体系总名、各阶段名称、晋升条件、战力验证和跨阶边界；
- 核心资源名称、来源、流通、价格/稀缺度参照、消耗和回收；
- 世界规则如何制造每10—30章可重复但可刷新的任务与冲突。

名称可以由模型完整拟定，但都属于候选，不自动成为正式事实。避免为显得完整而堆砌二十个无剧情功能的专名。

## 主角与核心人物

推荐案直接给出候选姓名、年龄、身份、初始处境、显性欲望、深层缺口、擅长、弱点、第一次主动选择和必须承担的代价。核心人物至少覆盖竞争者、制度入口、能力互补者、价值观对手与情感锚点；每人写明自己的目标、资源、秘密边界、与主角的合作/冲突理由及30章内状态变化。

从零开书时严禁沿用当前工作目录里现有小说的人名、关系和设定，除非用户在本次请求中主动指定。

## 可重复故事循环

用一句因果公式说明为什么能持续写，例如：

```text
获得目标或任务
→ 在制度与关系中遭遇冲突
→ 主角主动选择并利用能力、支付代价
→ 产生可见兑现
→ 资源/身份/信息/关系发生变化
→ 新状态打开下一层矛盾
```

循环可以重复，冲突来源、验证场、人物代价和解决方式不能原样重复。

## 原创映射

每次吸收市场信号或素材机制，至少重设以下四项：触发原因、主角目的、输入、处理规则、限制与代价、冲突对象、验证场、兑现证据、人物关系、后续影响。

对最近参考源额外比较：核心前提、金手指规则、人物关系、世界机构、前10章事件顺序、首次强兑现与长线主线。多个连续维度高度相似时必须重构，不能靠改名通过。
