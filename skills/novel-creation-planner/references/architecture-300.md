# 前300章滚动规划

300章规划是一张可以持续细化的结构地图，不是一次锁死的逐章表。

## 规划精度

- 1—10章：逐章；
- 11—30章：每2—3章一个剧情单元；
- 31—60章：每4—6章一个小弧；
- 61—120章：若干8—15章中弧；
- 121—200章：若干10—20章中大弧；
- 201—300章：若干15—25章大弧。

每完成10章细化下一窗口；每完成30章复核后续阶段。后续规划受已确认正文约束，候选不得覆盖已经发生的事实。

## 七阶段功能

| 阶段 | 必须完成的功能 |
|---|---|
| 1—3章 | 兑现题名与简介承诺；确立困境、主动选择、独特机制及第一次可见小兑现 |
| 4—10章 | 证明机制可重复；展示限制和代价；建立首批关系与对手；完成第一个小闭环 |
| 11—30章 | 跑通第一轮“冲突—成长—资源—身份—新问题”；完成首个正式阶段弧 |
| 31—60章 | 稳定核心故事引擎；扩大人物作用；第一次重大构筑选择；回收早期承诺并引入变化 |
| 61—120章 | 改变地图、制度或冲突规则；主线线索变成主动目标；能力遭遇克制；第一次系统性刷新 |
| 121—200章 | 权力结构和主角角色升级；长期对手成形；人物关系作出不可忽略的选择；第二次结构刷新 |
| 201—300章 | 多条早期因果汇流；主角开始影响规则；兑现阶段主线并打开下一宏观层级 |

## 阶段卡字段

每阶段记录：

- 中心问题；
- 主角目标、主动选择与代价；
- 核心冲突；
- 地图和制度规则；
- 主要人物及各自目标；
- 成长目标、代价与验证；
- 资源输入、输出、库存与消耗口；
- 主情绪、蓄压、可见兑现和余震；
- 主线新增证据、部分答案与下一问题；
- 新开债务与应还债务；
- 疲劳刷新手段；
- 阶段结束后的不可逆状态变化；
- 使用的素材ID与原创映射。

## 长线不是简单抬级

61章后至少两次改变以下两项以上：冲突规则、资源生态、权力结构、信息可见度、人物关系拓扑、主角责任、能力组合方式、胜利代价。新地图若只换地名和更强敌人，不算结构刷新。

## 素材覆盖矩阵

按七阶段检查：开篇承诺、冲突升级、可见兑现、人物变化、资源获得与消耗、能力限制与反制、地图/制度切换、主线揭示、高潮结算、余震冷却与疲劳刷新。

状态：

- `SUPPORTED`：正式 active 卡且当前适配；
- `ADAPTABLE`：DNA candidate 或旧卡可经原创重设使用；
- `GAP`：没有足够证据或适配机制。

对 `GAP` 生成素材缺口订单，交给独立拆书/入库流水线。订单只说明所需功能、适用阶段、目标情绪、前置条件、验收证据和禁区，不指定复刻哪本书。
