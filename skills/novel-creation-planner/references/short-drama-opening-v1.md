# NOVA 都市高武 × 短剧化开篇审核 V1（研究试验）

**用途：** 依据真实用户反馈修复三章测试小说开头，而不是打破已验证的世界/人物/技能边界；同时对下一本新书提炼结构 lesson。此文件是叙事设计门而非“与红果签约”保证。

## 诊断：为何《高武：这一拳，我练过》有连续性却看着慢？

已读真实前三章 A 版的独立审读事实：
1. 三章几乎一直留在同一场陪练测试（单地点、同两个拳手、三轮六十秒），微观脚步写得多，而超凡景观与外部世界状态变化少。
2. 第一章末才明确出现“败招重演”，第二章主要验证不能看未来、身体不自动变强、消耗注意力；第三章才得到钱。**能力解释/失败排除占用了体验奇迹和爽感的篇幅**。
3. 角色往往高度守规、理性沟通：医生合理、裁判公正、对手克制、商人守合同。现实可信，但相互冲突和情绪极差不够强。
4. 金钱合同清晰，力量尺度却弱：把“脉力”改为拳击体能，前三章的主要外部事件仍可成立；异兽、武者等级对社会秩序的改变没有在当前选择中形成不可替代的规则后果。
5. 测验→复测→课程→退款→互测→保险→实测延伸至几十章。**故事机制在进步，但表面行动反复是“试验合规与签字”，读者能感到的宏观位置提升较慢**。

这里的“节奏慢”不等于字数过多、缺少打斗，也不等于所有角色太理性。真实问题是**单位阅读时间内的不可逆变化、有效新信息和情绪差距不足**；专业流程反复解释了不变的原则，却没有及时引出足够不同的障碍与场景。

## 金手指：先体验，再命名，限制在失败中展示

设计“观众四问”，要求能在首个有具体结果的场景内回答：
- 主角能干什么？（**一句话**，外显可拍）
- 现在为什么需要它？（眼前不可回避的威胁/利益）
- 当场改变什么？（此前不可能的**可观察**结果）
- 代价是什么？（马上显示一个可见边界/症状/失去的选择）

研究试验例（不可直接覆盖 A 版）：
> 乔砚被打倒，视野短暂出现刚才自己的左脚与拳路的重叠影像。他尝试照着修正落脚，现实仍被击退；下一次终于以普通身体打中测力背心，数值在大屏上亮起。对手变步，影像变得错误，乔只能凭真实观察临场变招。读者先**看见重演的用途和失效**，之后再逐步得知脑内体感与营养代价。

这只是**镜头语言/结构建议**，原金手指不是能看见视觉屏幕或别人动作，也不会暂停世界。小说内主角的感知仍须符合“自身体感重演、两秒、不能预知、身体不自动强化”，外部可通过脚印、错位慢镜、影子等**影视表达方案**说明，不能把拍摄表现倒灌成小说超能力规则。

## 高武力量感：让世界规则改写眼前行动

最迟在第一主要冲突链中展现一项现代普通武道做不到的**可见能力/环境后果**：比如一阶受限的脉力在护壁留下测力衰减痕，二阶可直接让护壁震荡，或一次脉晶故障让现场不得不改变安全协议。只使用与既有“脉晶护壁、脉力限流、人体旧伤、正规安全系统”兼容的因果机制。

**不可**靠一拳秒杀全力高阶、神秘兽潮空降、突然多一个金手指、医训专家全部降智提高强度；高武感的标准是**力量和世界规则不可由普通现代拳击轻易替换**。

扩展角色目标：企业可以合法但仍利用有信息差的竞争策略，裁判可以公正但其裁决会损害某方利益，康复师可以专业但她的项目目标与乔砚的商业选择会正面冲突。

## 人物情绪：合理失控，不是傻反派

至少设计一个**可见的非理性行动**（焦虑/嫉妒/恐惧/愧疚/急功近利/盲目偏袒等）；必须写出：
1. 为什么此人无法冷静（处境与过去，不靠“天生恶毒”）； 
2. 他有真实控制权/筹码并采取什么可见行动；
3. 这次冲动具体夺走了谁的什么、迫使主角怎样选择；
4. 此人付出什么后果，是否仍保有后来改正或反制能力。

在《这一拳》的 B 版探索中，关耀可因销售时点/担责压力强推误导剪辑，陆骁可能因被赞助商看低而情绪性追加风险（仍须现场合法安全门约束），雷师傅可能因为不愿失去训练馆而短暂偏袒老客户、伤害乔砚。**只是三个备选方向**，不要求同时采用，更不能推翻 A 版已发生事实。

不要把所有人都写成通情达理的高效同事；也不要为了情绪强行牺牲行动逻辑。

## 短剧化结构：可拍、可剪、可传播，不等于抛弃小说

输出一张“开篇视听节拍表”，按观众感知而非字数划分：
1. 可拍的强冲突入场：谁在镜头前失去什么；
2. 大众一眼能看懂的能力和利益承诺；
3. 第一次主动抗争与失败/付费代价；
4. 主角以新能力造成立即可见的状态变化；
5. 冲突对象产生新的情绪与反制；
6. 一次小兑现 + 更大、不同性质的下一问题。

每个节拍标：
- `scene/location`、`characters`、`visible_action`、`stake`、`emotion_before_after`、`decision`、`state_change`、`next_watch_reason`;
- 如需视效，`live_action_vfx_cost_risk` 与 `animated_drama_fit` 分开。
- 动作要**一眼明白“我差一点够到、这次够到了”**，不凭九行步法讲解或脑内解说撑戏。
- 每个新场景必须提供新威胁、新选择、新结果三者之一；重复训练镜头若不改变现场条件、关系或资源，应蒙太奇或压缩。
- “视觉短剧化”是信息转换效率，不是机械每三百字一个耳光/反转；小高潮必须偿还之前建立的期待。

### 推荐审读窗口（实验目标，不是平台算法事实）

- 开场首场景：在早期直接呈现主角迫切需求、超凡环境与风险；优先强行动、减少合同与术语解释。
- 第1章：让读者明确获得能力的**可用结果**或即将使用的明确目标；若悬疑式延迟，必须有更强的独立悬念支撑。
- 前三章：至少一次小兑现与一次不同性质的关系/职业反转，不能三章只完成同一测试的三轮。
- 第4–10章：在训练之外出现一项新的更大场域/敌对目标/世界规则冲突，给观众理解“这真是高武世界”的理由。
- 第11–30章：不能连续是合同、保险、慢练与复测；高武等级、资源争夺或公众风险应真实改写职业局面，且有高能动作结果。
- 第31–100章：不能只靠升级更强反派；保留长篇因果和人物债务，同时增加动作奇观、角色失控、亲密与背叛、局势翻转等可视听化材料。

## 双版本盲读试验（研究）

**A 固定为** `research/urban-high-martial-creative-test-v1/chapter-01.md` 等三章已交付正文；不可覆盖。B 在另一个研究目录生成“第1章 + 第2–3章节拍表”，保留乔砚、伤势、败招回响、收入合同与人物可见事实，同时可局部重排场景（必须记录变更的因果）。

先让读者不看素材来源、不看模型评价，分别回答：
- 能否用**一句人话**描述主角能力和即刻代价？
- 读到哪里知道自己为何应追读？具体是哪次动作？
- 高武世界是否不可替换为现代拳击场？
- 哪个角色做出让人情绪起伏但有动机的选择？
- 第3章兑现是否值得前两章投入？
- 如果是**真人微短剧**，最难拍的镜头是什么；如果是**漫剧**，哪些能力表达反而有优势？

可记录首次吸引时点、规则理解正确性、重读次数、后续点击意愿（读者主动报告），不捏造真实平台完读率或播放量。B 无改进或破坏了A的可信度时应保留A；短剧化不是绝对优越。

**必要输出：** `opening_AB_readability_report.md`、`B_chapter01.md`、`B_chapters02_03_scene_beats.md`、`market_dual_research_status.json`。人工批准前不替换A，且不更新production。
