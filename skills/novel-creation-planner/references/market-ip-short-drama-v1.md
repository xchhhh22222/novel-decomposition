# NOVA 都市高武：商城发现→原站高在读核验→前10章实拆（研究V2）

> 2026-10-11 用户澄清：番茄版权商城只是**找书名的入口**，不研究版权授权、好书IP排名或改编公告。本轮只研究**在读人数较多的都市高武小说**的开篇金手指、爽点和节奏。不得仿写或复制原书独特人物、表达或连续事件链。

## 1. 商城正确入口

用户截图 URL：https://mall.fanqiecopyright.com/pc/search?key=book_name&value=&category_v2_id=1014 。实际页面处于 **「书籍」→「都市高武」** 类别，版权类型保持“全部”。截图首屏多张卡显示**小于1000在读**，证明“当前展示最前面”不等于“在读最多”。动态商城须在具有正常访问权限的本地浏览器逐卡核对，不能臆造API。

先翻页/加载更多，合法收集约30–50部不同原著（不够就收实际可得数量）；保存完整书名、作者（如有）、商城卡片URL、显示顺序、该卡“在读”文字、截图证据及日期。书名被省略号截断时点击卡片，**不要猜全名**。同书重复合并但保留原始位置。若官网确有最多在读排序选项则记录并验证，不能假设存在。

## 2. 原著主站核实热度和身份

拿“标题+作者”到番茄小说**原著页**搜索/核对，记录原著 book_id、作者、URL、分类都市高武、当前在读展示、数据日期、与商城同书的证据。只读到“小于1000人”这样的区间时只记录区间，**不能编造999或准确数量**；同档不强排先后。若缺作者或存在同名/漫画、不能确认为原著则状态 UNVERIFIED。

从**商城采到且原著身份已核实**的候选中，按主站真实在读档位/数值选高在读10部，保留候选及落选依据；样本不足或热度未核实，报告 HIGH_READ_10=PARTIAL，而不是补造。可另建**独立标注**的番茄都市高武阅读榜对照池，但不得把其书伪装成商城候选。

## 3. 真实前10章研究

使用本地Codex可用的番茄下载器，对选出的原著 book_id 在**合法可公开访问或用户获授权**的范围读取第1–10章：先 info 核对书名/作者/目录，再读取允许的章节，存日志、章节完整度与哈希；遇登录/付费/访问限制不绕过，缺章标 PARTIAL 或 metadata_only，不根据简介和目录编造剧情。

逐章记录：
- 首个即时危机、主角主动选择、利益冲突与情绪强度；
- 金手指的第一次展示、第一次**可见强效果**、第一次强兑现与代价/限制解释的顺序；
- 都市高武的不可替代力量表现；
- 非理性人物的真实动机、行动和后果，而非无脑打脸；
- 第1–3章兑现节奏、第4–10章第二个不同性质的爽点和下一章点击理由；
- 真人短剧/AI漫剧视听表达条件，保留正文证据章号。
不以故事简介、目录标题或商城上架状态冒充“读过前10章”。

读完后横向提炼有证据的结构lesson，再去冻结02–09素材库查询真实金手指、世界、人物、07开篇、08篇章、09机制，并产出三种互不相同、首3章有强效果且前10章有再次兑现的原创方案。不写新书正文、不改《这一拳》、不复制源作品标志性设定组合。

## 4. 值得整本拆解时的边界

初读优秀的作品先列入 FULL_BOOK_RESEARCH_REQUEST，记录为何值得整书、原著身份和后续章节权限；**等用户批准再动**。如访问权与来源规则允许，可为合法个人研究获取更多正文，但原著全文与NOVA创作素材物理分离，**无明确再分发/仓库存储授权，不得把受版权保护的整本原文上传GitHub或共享素材库**。允许将通过拆书QA的原创分析、抽象机制、非替代性结构笔记和来源指针作为 candidate 纳入素材库；须另行审批才能 active。
