# 新书金手指选型：能用优先

## 输入与边界

输入是新书题材、开篇冲突、长期资源入口、阶段高潮目标，以及已有 `per_book`/cluster 候选。候选不等于本书事实。先核对证据范围、QA 和未知项；不能根据前 50 章推断整本后期权限。用户没有确认时，只输出可选方案。

## 筛选顺序

1. 用一句白话写清 `做什么 → 得到什么 → 如何变强`。三步读不懂的，降低优先级。
2. 把金手指输入接到主角必须主动争取的东西：敌人、任务、钱、材料、名次、情报或关系博弈。只靠闭门重复练习且没有外部压力的，说明剧情发动机不足。
3. 让首次验证发生在开篇主冲突里；写出可观察的结果、旁观者反应和新风险。
4. 检查 50 章循环：输入是否可反复获取、收益是否有上限/选择成本、阶段高潮能否带来身份或权限变化。不要只计算数值涨幅。
5. 检查世界接口：稀缺资源、阶层门槛、制度、敌人生态是否支持该机制。若要改动新书世界硬规则才能接入，标为待确认。

## 输出

至少给 `可直接用 / 轻改后用 / 不适合` 的判断及证据。推荐项写清来源记录、已证实章节范围、运行公式、第一次爆点、前 50 章的资源循环、第一大高潮的兑现、持续使用的代价和未知项。允许推荐与参考书同类甚至同公式的通用机制，不强加“颠覆式创新”。

所谓轻改，只改接入资源、代价、公开验证方式或权限节奏中的一两项；改得过多则应承认是新机制，重新验算。不能搬运原书专名、独特台词、角色关系组合或连续事件链。
