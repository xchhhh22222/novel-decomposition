# 拆解 V1.3 入库规则

新拆书成果统一进入：

`<SHARED_ASSET_ROOT>/拆书入库区`

正式素材库不直接接收未经整理的整包拆解。标准链路为：

`完整拆解 → 迁移候选 → NEW/MERGE/SPLIT/HOLD → 用户确认 → 正式写入 → 索引验证`

## 分层

- 完整拆解：保留原貌和来源证据。
- 迁移候选：从完整材料复制出的原子化抽象，不替代完整材料。
- DNA 候选：人物卡、故事线、世界观、金手指等专项资产，默认 `candidate`。
- 正式套路卡：一张只表达一个可独立迁移的主机制，经过来源、去重、情绪和商业可用性审核后才可 `active`。

## 禁止

- 不把整书总结或完整人物线直接塞入套路素材。
- 不因目录位置自动升级状态。
- 不用高层摘要冒充章节证据。
- 不删除完整拆解来“节省重复”。
- 不把 `candidate`、`HOLD` 或 gap 记录计作正式可调用卡。

完整说明和批次模板见 `../../拆书入库区/00_拆解V1.3入库说明.md`。
