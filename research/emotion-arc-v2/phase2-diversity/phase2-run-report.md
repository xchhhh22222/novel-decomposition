## 3. Real causal weaving and counterfactuals

The provisionally selected commons path uses this cycle:

```text
sealed growth channels
→ protagonist cannot verify every plot alone
→ family receives real testing and suspension authority
→ family reserve limits how much seed can be shared
→ public allocation rules expose family choices to audit
→ audit prevents the protagonist from replacing governance with another self-sacrifice
```

Counterfactual results:

- Remove the growth scar: the protagonist can do all verification, so delegation and rotating testers lose causal necessity.
- Remove relationship authority: family conflict becomes commentary; the protagonist can decide sharing alone.
- Remove family security: allocation has no private cost and can be solved by generosity.
- Remove public responsibility: loans become private gifts and the arc collapses into a few chapters.

Equivalent removal tests are stored for every line in all four candidates. The Phase 2 validator requires every line to participate in a causal edge and have a non-decorative counterfactual change.
