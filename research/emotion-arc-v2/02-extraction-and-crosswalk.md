# Extraction and crosswalk procedure

1. Freeze the exact source repository commit and hash each referenced Git blob.
2. Require complete in-range chapter emotion coverage and a book-level QA PASS record.
3. Enumerate every local `promise_opened` locator before grouping any emotion line.
4. Separate expectations by payoff condition and character action, then construct ordered beats only from observed chapter changes.
5. Link to 05/06/08 only as contextual components. Chapter records remain the event authority.
6. Record each local-promise relation as `EXACT_SEMANTIC_MATCH`, `PARTIAL_RELATION`, `DISTINCT_PROMISE`, or `UNRESOLVED` with a written reason.
7. Create weave records after independent lines exist. Co-occurrence is `SHARED_EVENT` or `PARALLEL_ONLY`; causal types require an explicit state-changing bridge.
8. Bind every critical causal claim to a source record field. A real reference plus an unsupported explanation remains semantically unverified.
9. Create a macro arc only when a stage-level reader question organizes more than a one-off result. Record the chapter where cross-line organizing capacity first becomes observable and retain later sustaining evidence.
10. Create a handoff only from an observed trigger. Confirm the prior payoff contract remains intact and distinguish start, qualification, stage payoff and later dominance.

The machine reports evidence shape, source-field resolution and temporal preconditions only.
