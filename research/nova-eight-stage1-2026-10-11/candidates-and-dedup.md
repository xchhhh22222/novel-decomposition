## CAND-N8-A：强工具只补一个流程缺口

归档建议：主09，接口02/04/05。`decision=VARIANT_PROPOSAL`；不立即建立新母型。抽象功能：把已验证的强工具从“全包解题”改成“为普通操作争取一个受限窗口”，用不能覆盖的步骤产生战术与资源选择。

| 字段 | 内容 |
| --- | --- |
| 来源 | N8_06，book_id 7504849932138859545，13、16—19章；对应[循环Ⅲ—Ⅳ](books/N8_06.md)与源行号索引 |
| 初始困境 | 工具能改变某一局部条件，却不自动完成接近、命中、供给与撤离 |
| 压力来源 | 空间距离、敌方机动、消耗品和时间预算同时存在 |
| 金手指功能 | 输入可控局部窗口；输出操作机会；不输出全部行动结果。原著具体规则留在来源卡，不视作任意工具通则 |
| 主角行动 | 先测试，再承认覆盖缺口，选择正常操作路径与撤退阈值 |
| 翻盘关键 | 将工具用在最缺时间/最易出错的步骤，其他步骤仍需技术、资源或同伴 |
| 情绪变化 | 必胜预期→失败惊惧→主动调整→有限掌控 |
| 具体兑现 | 调整后的操作成功、物资实耗；没有把整个灾难都判成主角解决 |
| 状态变化 | 局部战果与经验留下，预算和补给减少，协作条件改变 |
| 下一循环 | 成功暴露供给/保护不足，打开谈判或组织入口 |
| 原创借鉴 | 重新设计触发原因、主角目的、工具覆盖面、消耗品、兑现证据和后果；不复制赌枪、鸟群、闭门复仇链 |

独立疲劳风险：每次都先失败再同样换招会变成固定节目；预算含糊会使受限表象失效；同伴无限补资源会取消限制。适配价值是早期“有特长仍须作决定”，不是给现有本书永久新能力。冻结《异兽经》前期能力不含暂停流程，这张卡只能启发解析与选择怎样承担局部环节，不能自动解锁新功能。

未解决问题：单书证据；原著15—16章时间余额存在口径差；19—20章全镇获救归他人。晋升前需另书同功能实例及预算审计。

## CAND-N8-B：选择性加工接入既有承载体

归档建议：主02，接口03/04/06/09。`decision=SUBFUNCTION_VARIANT_PENDING`。抽象功能：面对不能直接用的高价值输入，分辨可保留与必须删除的性质，再接到已有生产条件；下一问题来自规模扩张，而非再送一种全新资源。

| 字段 | 内容 |
| --- | --- |
| 来源 | N8_01，book_id 7631863518148430873，11—13、17—20章；[资源研究卡](books/N8_01.md) |
| 初始困境 | 直接使用会损害受益对象；即使加工成功，现有系统也承载不起扩张 |
| 压力来源 | 污染、人口/消耗增长、外部采购与资源控制利益 |
| 金手指功能 | 原著提取/剥离与赋予使输入性质可选；需要目标、承载体、资源及行动。长期容量未核实 |
| 主角行动 | 先决定留什么、删什么，再为真实缺口采购，拒绝会损害控制权的资本条件 |
| 翻盘关键 | 增强既有资产的功能，使旧资源能完成此前办不到的任务 |
| 情绪变化 | 高价值不可用的焦虑→性质改变可验→产出期待/资源爽→容量忧虑 |
| 具体兑现 | 11章负面剥离与培养，19章生产嫁接有实际表现；20章新采购尚无战果，不列已兑现 |
| 状态变化 | 种群与生产条件改变；资金、生态结构和秘密维护成为变量 |
| 下一循环 | 更高产出带来承载/市场/防护需求，不能从面板增益直接跳到永久富足 |
| 原创借鉴 | 改输入性质、加工权限、目标、承载方式、稀缺成本和规模后果；删除眷族与器官移植包装 |

独立疲劳风险：所有负面可无条件删除会使规则失去威胁；嫁接无限叠加会取消取舍；不断采购并报数字会变成经营流水。相较GF006的随机变异与筛选，本例强调定向选择；相较返还类，获取端仍需主动行动。保留为子功能比较，不另建泛化“废物变宝”母型。

适配限制：路远源印位与《异兽经》阶段不允许本例的无限群体赋予、剥离/熔炼与重构，不能写入当前本书能力事实。可学习“选择承担机会成本”的功能，能力本身需未来另项目授权。父亲康复、母虫构筑长期代价、20章新水域战果未知；免费馈赠与数量矛盾影响可迁移性。

## CAND-N8-C：共同胜利由不同目标主体完成

归档建议：主05，接口06/08/09。`decision=RELATION_VARIANT_PENDING`。抽象功能：两方为了不同目的进入同一事件，控制权变化迫使行动者作自己的决定；最终结果同时包含硬收益与价值选择，不能把一个人的功利目的写成所有人的共同动机。

| 字段 | 内容 |
| --- | --- |
| 来源 | N8_03，book_id 7592279900040465433，11—20章；关键14、18—20；[双主体卡](books/N8_03.md) |
| 初始困境 | 一方追求可量化收益，一方承担现场生命与道德后果，最省事方案不能同时满足 |
| 压力来源 | 信息迟延、不同目标、控制窗口结束、受害者当下损失 |
| 金手指功能 | 来源中的操作与回档暂时提供执行能力；窗口结束后不能解释行动者的全部救援。未知隐藏状态独立标注 |
| 主角行动 | 操作者布局获取机会；行动者在失去控制后主动救助并承担成本 |
| 翻盘关键 | 决定权从方案制定者移到现场承担者，后者选择改变胜利包含的内容 |
| 情绪变化 | 功利期待→失控与伤害→自主守护→具体人物获得补偿的感动 |
| 具体兑现 | 敌被击杀、被救者存活与收到食物、恐惧变成感谢；经验不是唯一验收项 |
| 状态变化 | 能力/身体收益与自主行动证据同时留下，但没有证明两方永久价值一致 |
| 下一循环 | 外部任务继续提供共同入口，不同目标仍需重新谈判 |
| 原创借鉴 | 使用两个独立行动者而非占据身体；重设共同任务、权限、利益、责任、救助方式和成本，禁止复用餐馆暴行—矿工感染—母女救助事件链 |

独立疲劳风险：每场都让功利者闯祸、善良者补救会脸谱化；身份/操控复杂会增加读者进入成本；隐藏救援力量若无限有效，会使自主选择的成本归零。与旧共担极限区别：不是给退路后主动并肩；与增益让渡区别：控制到期并非已证实的主动让渡。只保留目标差与结果归属的变体。

适配价值：让核心队友/女主保有独立目标和决定权，关系推进同时承担共同任务、价值冲突与秘密边界。本书不能迁入夺舍、原主或第二外挂；关系走向与重大能力仍需用户确认。隐藏状态与感染解法、下一阶段关系是否变化尚未明。
